# Ourtone

[简体中文](README.md) · English

A purely frontend music creation and rhythm game website. Turn any MIDI track into a playable rhythm game chart, with basic DAW functionality built in.
Ourtone features two visual themes, Day and Night, inspired by MyGO!!!!! and Ave Mujica respectively.

- **Website (Vercel)**: <https://ourtone.fun>
- **For users in mainland China**, we recommend the Bilibili-hosted version for more reliable access: <https://www.bilibili.com/toy/ourtone>

## Features

- **Rhythm Game**: Click any track on the homepage to enter Play Mode, or select multiple tracks to play them together. By default, note playback follows the player's actual input timing. Supports touch and slide controls on mobile devices.
- **Studio**: Arrangement editor, piano roll, sound design, mixer, and microphone recording. Supports exporting MIDI, WAV, and MP3.
- **Music Generator**: Experimental procedural music generation in five different styles.
- **MIDI Import**: Import MIDI files for editing or rhythm gameplay.
- Built-in instrument sounds are synthesized in real time using the Web Audio API, without requiring external instrument sample libraries or a server-side backend. Data is stored locally in the browser (IndexedDB) and can be backed up or restored through the "⋯" menu.

## About the Built-in Songs

The live website includes fan-made MIDI arrangements sourced from the internet. Rights to the underlying compositions and MIDI arrangements belong to their respective rights holders, so these songs are **not included in this repository**. This repository includes only one example song generated by Ourtone's built-in music generator.

## Known Performance Issues

Real-time audio synthesis combined with graphics rendering makes Play Mode relatively demanding.

Some performance issues remain on mobile devices, particularly iOS:

- Occasional frame drops in Play Mode on iPhone and iPad, especially in the Night theme.
- Devices may become noticeably warm during extended sessions.

**Help with performance is very welcome!** Some diagnostics:

- Add `?perf` to the URL for a performance panel (frame times, GPU time and more).
- `?playRenderer=canvas|gpu|retained` switches Play Mode's renderer. iPhone and iPad use `retained` by default, everything else `canvas`.
- The code lives in `src/rooms/stage/`: `PlayMode.svelte` (Play Mode), `warp.ts`, `gpuCanvas.ts`, `highwayBatch.ts` (WebGL drawing).

Issues and pull requests are welcome.

## Running locally

Requires Node.js 20.19 or newer.

```bash
npm ci
npm run dev          # local dev server
npm run build        # build the site into dist/
npm run build:single # one self-contained HTML file in dist-single/
npm run check        # type check
```

The site is fully static: serve the contents of `dist/` from any static host.

Offline tests (Node):

```bash
npx vite build -c vite.test.config.ts
node tests/out/chart.js   # Play Mode chart checks
node tests/out/gen.js     # song generator checks
```

### Fonts

The fonts in `src/assets/fonts/` are cut down to the characters the site uses. After changing interface text, put the full font files in `fonts-src/` (file names in `scripts/subset-fonts.py`, all available from Google Fonts) and run `npm run fonts`.

## Layout

- `src/rooms/stage/`: the Stage and Play Mode
- `src/rooms/studio/`: the Studio
- `src/lib/audio/`: synthesis, sounds, mixing and export
- `src/lib/music/`: song model, music theory, MIDI import
- `src/lib/gen/`: the song generator
- `src/lib/art/`: drawing, icons and the wordmark
- `src/data/`: the built-in songs
